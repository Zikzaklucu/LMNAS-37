# LMNAS 37

Standalone static coming-soon page for LMNAS 37.

## Run

```bash
cd "LMNAS 37"
python3 -m http.server 8000
```

Open `http://localhost:8000/`.

## Files

- `index.html` — minimal coming-soon cover markup
- `style.css` — jungle cover art direction, local fonts, and responsive layout
- `Assets/` — Figma-exported decorative assets, texture, and local font files
- `script.js` — reserved for future navigation behavior; not loaded by the current page

## Edit before launch

The current page intentionally shows only the large `LMNAS 37 / Coming Soon` heading. Add official event copy, dates, contacts, registration destination, rules, and downloadable resources only after the LMNAS 37 committee has confirmed them.
